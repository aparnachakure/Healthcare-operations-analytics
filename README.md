# Healthcare Operations & Patient Analytics

This project answers operational, financial, patient, and readmission questions
for a synthetic multi-department hospital. It is designed as one connected
analytics workflow rather than a collection of unrelated tool demos.

## Project flow

1. Define the business problem and decision questions.
2. Inspect the provided workbook `excel/Healthcare_Operations_Analytics.xlsx` and use the checklist in `excel/README.md`.
3. Clean and feature-engineer admissions with `python/clean_healthcare_data.py`.
4. Load relational tables into PostgreSQL.
5. Answer business questions with `sql/business_questions.sql`.
6. Reuse the same data model for Power BI pages and measures.
7. Train an explainable readmission baseline with `python/train_readmission_model.py`.
8. Present recommendations in the healthcare analytics dashboard.

## Data source

The current build uses deterministic synthetic data generated by
`artifacts/api-server/data/seed_healthcare.sql`. It contains 750 patients,
1,800 admissions, 6 departments, 12 doctors, treatments, billing records, and
lab results across 2025. Financial values are displayed in Indian rupees (₹).
It is safe for portfolio and interview use and is not clinical data.

## Dashboard

The runnable dashboard is the primary user surface. It exposes executive KPIs,
monthly trends, department performance, condition cost profile, readmission
factor breakdowns, and a recent admissions worklist through the shared API.

## ML boundary

The baseline logistic regression is for analytical demonstration only. It is not
a clinical decision tool, diagnosis system, or patient-facing risk score.

## Power BI handoff

`powerbi/model-notes.md` defines the recommended star model and report pages.
`powerbi/measures.dax` contains the reusable KPI measures for the Power BI
semantic model.
## Deliverables

- `excel/Healthcare_Operations_Analytics.xlsx` — raw tables, quality checks, and initial pivot analysis.
- `powerbi/data/` — Power BI-ready dimension and fact CSVs.
- `powerbi/model-notes.md` — recommended star schema and report design.
- `powerbi/measures.dax` — reusable DAX measures.
- `key_findings.md` — descriptive findings from the synthetic dataset.
